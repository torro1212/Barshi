# HT Draw Analyst — מנתח תיקו במחצית

מערכת ווב שמנתחת משחקי כדורגל וחוזה אילו מהם יסתיימו בתיקו במחצית (Half-Time Draw), עם תמיכה בשתי ליגות: 🇪🇸 לה ליגה ו-🇮🇱 ליגת העל.

## הרצה

```bash
npm install
npm run dev
```

נפתח בכתובת http://localhost:5173 — עובד מיד במצב דמו, ללא צורך במפתח API.

## שליפה אמיתית (אופציונלי)

בפאנל השליפה אפשר להזין מפתח Gemini API (נשמר ב-localStorage). השליפה משתמשת ב-Gemini 2.5 Flash עם Google Search Grounding. אם השליפה נכשלת — המערכת עוברת אוטומטית למצב דמו עם הודעה.

## מה יש בפנים

- **בורר ליגה** — לה ליגה (20 קבוצות) / ליגת העל (14 קבוצות בעברית), משקולות למידה נפרדות לכל ליגה
- **אלגוריתם 4 שכבות** — פרופיל (35%), H2H (20%), פורמה (25%), רצפים (20%) → ציון 0–100
- **המלצות** — עד 6 ביום, סף מינימום 50 (ניתן לכוונון), TOP PICK בציון 75+
- **מסך תוצאות** — הזנת תוצאות מחצית (`0-0`, `1-1`) וחישוב אחוז פגיעה
- **מנוע למידה** — Grid Search על משקולות + זיהוי 5 תבניות + סף מומלץ + F1, נשמר בנפרד ב-`learned_weights_laliga` / `learned_weights_israel`
- **המחזור הבא** — מחזור מלא (10 / 7 משחקים) עם TOP PICKS בציון ≥ 65 וטעינה לניתוח

הכול נשמר ב-localStorage (`ht_draw_analyst`). כלי ניתוח סטטיסטי בלבד — לא ייעוץ הימורים.
