# HT Draw Analyst — מנתח תיקו במחצית

מערכת ווב שמנתחת משחקי כדורגל וחוזה תיקו במחצית (Half-Time Draw) בשתי ליגות:
🇪🇸 לה ליגה ו-🇮🇱 ליגת העל. **נתונים אמיתיים בלבד — אין מצב דמו.**

## הרצה

```bash
npm install
npm run dev
```

## איך זה עובד

- **נתונים אמיתיים ארוזים באפליקציה:** 4,560 משחקי לה ליגה (2014–2026) ו-719 משחקי
  ליגת העל (2022–2025), כולל תוצאות מחצית. נבנים מ-`data-laliga/` ו-`data-israel/`
  עם `npx tsx scripts/build-stats.ts`.
- **מודל נפרד לכל ליגה:** רגרסיה לוגיסטית על 15 פיצ'רים אמיתיים (פער כוחות, קצב
  שערים, התקפה/הגנה, מיקומי טבלה, פרופילי תיקו-מחצית, H2H ועוד), מאומנת בנפרד
  לכל ליגה על הנתונים שלה.
- **שני צדדים להמלצה:** לכל משחק מחושב P(תיקו במחצית). כשההסתברות נמוכה מהסף —
  המלצת **"אין תיקו במחצית"**; כשהיא גבוהה (בלה ליגה בלבד) — המלצת **"תיקו במחצית"**.
- **דיוק מדוד, לא מובטח** (בדיקה עיוורת walk-forward, מחוץ למדגם — פירוט ב-BACKTEST.md):

| ליגה | "אין תיקו במחצית" | "תיקו במחצית" |
|---|---|---|
| 🇪🇸 לה ליגה | **64.7%** (P ≤ 0.38) | 50.6% (P ≥ 0.48) |
| 🇮🇱 ליגת העל | **62.0%** (P ≤ 0.36) | לא מומלץ (44% — מתחת לרף) |

- **משחקים אמיתיים:** שליפת לוח המשחקים דרך API-Football (מפתח חינמי מוזן בממשק,
  נשמר בדפדפן בלבד), או הוספה ידנית ע"י בחירת שתי קבוצות — הסטטיסטיקות תמיד
  מהנתונים ההיסטוריים האמיתיים.
- **מסכים:** ראשי, משחקים, ניתוח (עד 6 המלצות), תוצאות (הזנת תוצאות מחצית ואחוז
  פגיעה), דיוק (הדיוק המדוד + הרשומה האישית שלך), המחזור הבא.

## סקריפטים

```bash
npx tsx scripts/build-stats.ts               # בניית חבילות הנתונים לאפליקציה
npx tsx scripts/research.ts data-laliga SP1 4  # מחקר ולידציה walk-forward
npx tsx scripts/backtest.ts data-laliga SP1    # בדיקת האלגוריתם הישן (v1) להשוואה
npx tsx scripts/fetch-israel.ts --key <KEY>    # רענון נתוני ליגת העל מ-API-Football
```

כלי ניתוח סטטיסטי בלבד — לא ייעוץ הימורים.
